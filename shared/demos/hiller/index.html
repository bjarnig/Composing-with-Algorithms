Generate and Test

The method of Lejaren Hiller and Leonard Isaacson for the Illiac Suite (1957). A random number proposes a note, a set of rules tests it, and the note is kept only if every rule accepts it. Rejected proposals are drawn as crosses, with the rule that refused them. Each added rule makes the line more orderly and makes the machine throw more away.

accepted, the melody rejected proposal

With no rules the result is a uniform random melody. Every rule is a constraint on the next note given the last one, which is why the rules have to be tested one note at a time.
