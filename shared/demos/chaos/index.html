Chaotic Maps

Iterated functions as sound sources. The maps and their default parameters follow ChaosFunctions.scd; the two playback modes follow ~playStreamFreq (pitch) and ChaosUGens (audio rate).

Start with the gain low. Some parameter settings are very loud and very bright.

For the one-dimensional maps the upper panel is the bifurcation diagram: the parameter runs left to right and the attractor is plotted vertically, so you can see the period doubling and the onset of chaos. The gold line is where the parameter currently sits — drag it and you hear the same transition you are looking at. For the two-dimensional maps the upper panel is the phase portrait, x against y. The lower panel is always the recent time series, the values actually being sonified. In audio rate mode each iteration is one sample-and-held sample, so rate behaves like a frequency; in pitch mode each iteration is a short percussive tone whose frequency comes from the map value.
