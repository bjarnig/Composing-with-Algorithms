Dynamic Stochastic Synthesis

Xenakis’ GENDYN in the browser. Parameter names follow SuperCollider’s Gendy1 / Gendy3, so this runs beside Gendy.scd in class.

Start with the gain low. Stochastic synthesis produces broadband signals.

Each control point holds an amplitude and a duration. Every time the oscillator reaches a point, both values take a random step drawn from the chosen distribution, scaled by ampscale / durscale, and are mirrored back inside their bounds — so the waveform never resets, it only ever walks away from where it was. In Gendy1 each point’s duration maps to an instantaneous frequency between minfreq and maxfreq; in Gendy3 the cycle is forced to freq and the durations only redistribute time inside it. The distributions are standard shaping forms of a uniform variate, not a bit-exact port of the SuperCollider UGens, so shapes correspond but individual samples will not.
