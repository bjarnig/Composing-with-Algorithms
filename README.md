# Composing with Algorithms

An introduction to algorithmic composition, its applications, history and
implementations. Participants learn to program sound, control and musical
behaviour, using the SuperCollider environment alongside short introductions
to other platforms.

Topics include probabilities, generative algorithms, complex systems and
selection principles, covering technique as well as practical applications
and musical examples.
